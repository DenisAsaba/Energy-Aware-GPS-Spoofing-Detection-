The nested project is the authoritative M0–M9 research project for source code, milestone status, configurations, methods, and canonical reports. The older workspace root is retained as historical material; its `TASKS.md` status (M3 complete) is not the authoritative M0–M9 status. Keep those paths identified as root-project evidence; they are not files under the nested project and must not be presented as if they were.

This inventory records the source used for the consolidated summary. Repository-relative paths refer to the authoritative nested project. Explicit `external_historical_root_project/` references preserve provenance for evidence outside that repository. No historical artifacts in either project were modified for this consolidation.
